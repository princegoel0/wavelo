# Changelog

## 0.1.0

- Initial dependency-free core, catalog, DOM and Web Component integrations.
- Typed framework adapter bridges for React, Angular, Vue, and Svelte.
- Registry-driven static documentation gallery.
- Type, unit, accessibility-contract, package, and catalog validation scripts.
- 69 active catalog designs with 12 documented deprecated aliases that preserve
  their public imports and map to canonical designs.
- Package-local README and MIT license files included in every publishable
  tarball.
